# DINERO

**Свои деньги. Свои правила. / Your money. Your rules.**

Personal finance for Mac: accounts, cash, investments, cash flow, goals, recurring plans and reminders. Russian and English interface.

[Website / Сайт](https://dinero.freedev.app) · [Downloads / Загрузки](https://github.com/nailalekperov/dinero-releases/releases/latest)

## macOS

Requires macOS 26 or later. Apple Silicon and Intel.

1. Open the latest release and download **DINERO-0.9.0-macOS.zip** from Assets.
2. Extract the archive and move **DINERO.app** to Applications.
3. Open the app and create your local profile.

The current build is ad-hoc signed and has not been notarized by Apple. macOS on another computer may warn about it or block installation.

## About this repository

This repository contains ready-to-use application downloads and release information. The DINERO application source code is not included. GitHub-generated source archives contain only the public repository files, not the application source.

Financial data stays on your device in encrypted local files. Application downloads do not contain the developer's personal financial records.
